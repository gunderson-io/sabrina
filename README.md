# The Circus

Sabrina's blog, built with [Eleventy](https://www.11ty.dev/) and published at https://gunderson.io/sabrina/.

```
npm install
npm start      # dev server
npm run build  # writes _site/
```

Posts live in `src/posts/` as `YYYY-MM-DD-slug.md`; pushing to `main` deploys via GitHub Actions.
